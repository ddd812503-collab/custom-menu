# Custom Background (Выбор фона) — Fabric, Minecraft 26.2

Мод заменяет фон главного меню и всех экранов вне мира (выбор мира, настройки, мультиплеер и т.д.).

* В главном меню справа снизу — кнопка **«Фон»**.
* Внутри: 8 встроенных фонов + «Стандартный», выбор применяется сразу и запоминается.
* **Свои картинки:** положите PNG/JPG/BMP/GIF в папку `.minecraft/custom_backgrounds/`
  (кнопка «Открыть папку со своими») и нажмите «Обновить список» — или просто **перетащите файл в окно игры**
  на экране выбора фона. Картинки больше 1920×1080 уменьшаются автоматически.
* Выбор хранится в `config/custombg.properties`.

## Сборка jar

Нужен **JDK 25** и интернет.

    ./gradlew build          # Windows: gradlew.bat build

Готовый мод: `build/libs/custom-background-1.0.0.jar` (файл `-sources.jar` не нужен).
Положите его в `.minecraft/mods/` вместе с Fabric Loader (>= 0.18.4) и Fabric API для 26.2.

`tools/gen_bg.py` — скрипт, которым сгенерированы встроенные фоны (Python + Pillow + numpy).
